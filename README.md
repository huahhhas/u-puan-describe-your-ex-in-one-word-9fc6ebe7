# unsubscribed

One word for an ex: **unsubscribed**.

No dramatic breakup speech, no blocked-number saga — just quietly opted out of the newsletter. The relationship ended the way a free trial does: the renewal never came, the emails stopped, and nobody even noticed until the inbox went silent. Instantly readable, a little petty, and exactly how modern heartbreak works — you don't unfriend them, you just stop receiving updates.

## Run it

```bash
python3 main.py
```

This writes `unsubscribed` (plus a trailing newline) to `/output/entry.txt`. Pass an optional output path as the first argument for local testing:

```bash
python3 main.py /tmp/entry.txt
```
